## How it works

<p align="center">
  <img src="assets/how-it-works.svg" alt="From one retrieve to every question, offline" width="100%">
</p>

One `sf project retrieve` against your org. The vault and graph build
locally. From then on, every question your AI assistant answers is served
from the local store — no live API calls during the conversation, no
record-level data, no network.
