## R7-F3 — Embedding index parity gate + regen entrypoint

**packages/mcp** · _feat_

- Added `packages/mcp/scripts/check-embedding-index.mjs`: gate script that
  verifies `data/embedding-index.json` covers exactly the V01_TOOLS roster
  (tool count == vector count, no missing, no orphan vectors). Imports the
  authoritative roster from `dist/src/tools/index.js` when built; falls back
  to regex-parsing `src/tools/index.ts` for local dev without a prior build.

- Added `scripts/regen-embedding-index.mjs` (product root): single entrypoint
  to rebuild the embedding index at integration merge time — runs `pnpm build`
  for the mcp package, then `build-embedding-index.mjs`, then the parity check.
  **Do not run in parallel fleet branches** (index regeneration causes
  unnecessary bit noise; regenerate only at integration merge).

- `ROUND_DP` remains pinned at `1e6` in `build-embedding-index.mjs`
  (deterministic single-point regeneration).

- Added `embed:check` script to `packages/mcp/package.json` and
  `check:embedding-index` / `regen:embedding-index` to the root `package.json`.

- Wired `ci:embedding-index` step into the QA commit-gate (runs after
  `ci:build`; included in `FAST_STEPS`).
