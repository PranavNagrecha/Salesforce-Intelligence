### Fixed
- **The end-to-end MCP smoke test hardcoded the exact roster count this same release changed, and nothing local ever ran it to notice.** `packages/mcp/e2e-smoke.mjs` asserted the `core` profile advertises exactly 19 schemas and used `sfi.org_overview` as its example of a tool that is NOT directly invokable under `core` — both literally true until this release's roster-expansion fix (`core` grew to 25 tools, `org_overview` among the six newly promoted). The script is not part of the vitest suite and nothing in this project's local gate list runs it, so this drifted silently through every local test run for the rest of the release and was only caught on the first real push to `main`, where CI runs it for real. Both assertions now derive from the same `CORE_PROFILE_TOOLS` set the server itself gates on — the expected count, and the non-core example tool used to prove denial — imported from the package's own public API rather than restated as a second, driftable copy.
