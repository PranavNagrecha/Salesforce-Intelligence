### Fixed
- **The release workflow asked the MCP Registry to register a version npm was not serving yet.** npm accepts a publish minutes before it serves it, and the registry looks the exact version up on npm before registering it — so on 0.3.3 the registry step got a 400 ("version '0.3.3' was not found … Wait and retry") two seconds after npm took the package, and the SBOM and GitHub Release were skipped until a manual re-run (npm served the version 2 min 45 s later). The registry step now retries that one rejection every 30 s for up to 10 minutes; any other failure is still fatal on the spot, and the not-found case is tested before the duplicate-version check, so it can never pass as an idempotent re-run.
