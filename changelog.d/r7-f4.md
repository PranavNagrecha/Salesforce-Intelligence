# R7-F4 — Gate hardening: known-failures baseline + --product-root + per-tool golden record

**Type:** harness / qa  
**Scope:** sf-intelligence-qa (gate scripts, not product code)

## Changes

- **Known-failures manifest** (`sf-intelligence-qa/config/known-failures.json`): four pre-existing,
  backlog-tracked residuals are now allowlisted with expiry dates (2026-10-01). The gate treats them
  as suppressible warnings rather than hard failures; NEW unmatched reds still fail. Expired entries
  warn loudly and revert to hard failures.

- **`--product-root <path>` CLI flag** (commit-gate.mjs + paths.mjs): overrides `productRoot` with
  highest priority (above `SFI_PRODUCT_ROOT` env and targets.json). Asserts `sfiMcpBin` resolves
  under that root; fails with a clear error on binary/root mismatch unless `--allow-external-bin`
  is passed.

- **Per-tool golden recording** (`golden-diff.mjs`): `--record <toolName>` (or `--record=sfi.foo`)
  rewrites only that tool's snapshot and leaves the rest of `golden/` intact. Full `--record`
  (all-or-nothing) now warns explicitly that it is dangerous. Bare names and `sfi.*` names both
  resolve correctly.
